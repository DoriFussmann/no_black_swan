# No Black Swan

Public marketing site for noblackswan.com (Astro, static). Articles are published into `site/src/content/articles/` by TNV.

- `npm install` then `npm run dev` (from the repo root)
- `npm run build` builds and runs the SEO audit
- Brand mark: `site/src/assets/brand/mark.svg` (NBS monogram; the compass alternative is in `site/src/assets/brand/options/`). Favicon, `public/logo.png` and `public/og-default.png` are generated from it.
